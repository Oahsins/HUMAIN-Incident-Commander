An AI agent that recovers failing systems using emergency response protocols

It surveys every component in a fixed order, triages, fixes with six bounded actions, rechecks, then hands over. Below is one real run on a test bank: two faults at once, recovered in 14.6 s with two allowlisted actions, then confirmed by separate code that scores the customers' own logs.

On sealed exams it had never seen: 39 of 40 bank incidents, against 19 of 40 for a scripted runbook. On dispatch, a second system built after the freeze: 13 of 20, against 9 of 20. Full results

      What this is

      A step-by-step replay of one real run, filmed Fri 30 Oct 2026, 22:08 Riyadh. The bank, its 20 simulated customers, the browser customer, the survey, both actions, every recheck and the checker's verdict all ran live.

      The model's two answers (triage and the handover text) came from a recording of an earlier live run of the same frozen agent, so the run needed no key. The SBAR quotes that earlier run's figures.

      Break the bank, then watch the agent recover it

      Everything runs on your own computer or in a browser terminal. You need Python 3.11 or later. The bank and its customers start locally, and nothing leaves your machine except the model calls.

      No install · pick a case, press Run

      Run the agent from a web console

      The repository ships a small web console. Pick any practice incident and a mode, press Run, and watch the frozen agent's survey, actions, rechecks and handover arrive live, followed by the checker's verdict. It drives the same run.py commands shown below.

      Open in GitHub Codespaces Needs a free GitHub account. On GitHub's page, click Create new codespace. It builds for 2 to 3 minutes, then the console opens in a new tab. If the tab is blocked, open the Ports tab and click the globe next to “Incident console”.
